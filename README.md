# FloorPlanMaker（間取り図メーカー）

[日本語](#日本語) | [English](#english)

---

## 日本語

部屋を配置するだけで、ドア・窓・家具入りの間取り図を作成できるWebツールです。PNG保存・印刷にも対応しています。インストール不要で、PC・スマホの両方で使えます。

すべての処理はお使いの端末内で行われます。作成した間取り図がどこかに送信されることはありません。

**👉 [今すぐ使う](https://daigorou-addon.github.io/floorplanmaker/)**

Windows向けのデスクトップ版もあります: [FloorPlanStudio](https://github.com/daigorou-addon/FloorPlanStudio/releases)

### 主な機能

- **部屋**: LDK・洋室・和室・寝室・浴室・トイレ・玄関・廊下・バルコニーなど、31種類のパーツを配置できます（庭・駐車場・敷地境界線などの屋外パーツも含む）
- **ドア・窓**: 開き戸 / 両開き戸 / 親子ドア / 引き違い戸 / 片引き戸 / 折れ戸 / 開口 / 引き違い窓 / FIX窓 / 掃き出し窓 / 出窓。壁の近くへドラッグすると吸着します
- **設備・家具**: キッチン・冷蔵庫・洗濯機・浴槽・ベッド・ソファ・テーブル・階段（直階段・L字・かね折れ・U字・らせん）・吹き抜け・方位記号・テキスト・車・木・塀・門など
- **自由な編集**: ドラッグで移動、枠の■で大きさを変更。部屋の角の○をドラッグすると、角を斜めにカットできます
- **複数階**: 階を追加・削除して、1F・2Fなどを作成できます
- **シンプル／詳細**モードの切り替え
- **元に戻す／やり直し**（Ctrl+Z / Ctrl+Y）、ズーム
- **自動保存**: 内容はお使いのブラウザに自動で保存されます
- **JSON保存・読み込み**、サンプル間取りの読み込み
- **PNG保存** と **印刷**
- **表示テーマ切り替え** と **6言語対応**（日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español）

### 使い方

1. 「部屋」タブから部屋を選んで、キャンバスに配置します。
2. 「ドア・窓・他」「設備・家具」タブから、ドアや窓、家具を追加します。
3. ドラッグや枠の■で、位置と大きさを調整します。名前や向きは「選択中」から変更できます。
4. 「PNGで保存」または「印刷」で出力します。

## English

FloorPlanMaker is a web tool for creating floor plans with doors, windows, and furniture just by placing rooms. You can save as PNG or print. No installation is required, and it works on both desktop and mobile.

Everything is processed on your own device. Your floor plans are never sent anywhere.

**👉 [Try it now](https://daigorou-addon.github.io/floorplanmaker/)**

A desktop version for Windows is also available: [FloorPlanStudio](https://github.com/daigorou-addon/FloorPlanStudio/releases)

### Features

- **Rooms**: 31 room types, including living/dining/kitchen, Western and Japanese-style rooms, bedroom, bathroom, toilet, entrance, hallway, and balcony, plus outdoor parts such as garden, parking, and site boundary
- **Doors and windows**: swing / double / parent-and-child / sliding / single sliding / folding doors, openings, sliding / fixed / floor-to-ceiling / bay windows. They snap to walls when dragged near them
- **Fixtures and furniture**: kitchen, fridge, washer, bathtub, beds, sofa, tables, stairs (straight, L-shaped, dogleg, U-shaped, spiral), voids, compass, text, car, tree, fence, gate, and more
- **Free editing**: drag to move, and use the ■ handles on the frame to resize. Drag the ○ at a room's corner to cut the corner diagonally
- **Multiple floors**: add or delete floors to make 1F, 2F, and so on
- **Simple / Detailed** mode switch
- **Undo / Redo** (Ctrl+Z / Ctrl+Y) and zoom
- **Auto-save**: your work is saved automatically in your browser
- **JSON save / load**, and a sample floor plan
- **PNG export** and **printing**
- **Light/dark theme** and **6 languages** (日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español)

### Usage

1. Pick a room from the "Rooms" tab and place it on the canvas.
2. Add doors, windows, and furniture from the "Doors & more" and "Furniture" tabs.
3. Drag and use the ■ handles to adjust position and size. Change the name and direction from "Selected".
4. Export with "Save as PNG" or "Print".
